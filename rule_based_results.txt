V5, 200 000 games
Same algorithm, with an extra hesitation rule:
If the AI hesitates between several cards, it checks how the cards already played score points.
The AI chooses the card that matches the main scoring family among the cards already played.
If several families have the same number of scoring cards, the AI compares how many points each family is currently generating and chooses the card from the family with the highest score.
If there is still a tie, the AI uses this priority order: pineapple → deer → stone → parchment → night → the rest.
